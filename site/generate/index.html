Manifest Generator

Declare — in a signed, machine-readable file — what AI agents may do with your content. Everything below runs in your browser: your keys never leave this page. No account, no server, no tracking.

1 · Who you are

The name agents will see, and the site the policy covers. Everything you publish there falls under it unless you add items in Advanced mode later.

2 · What agents may do

Four common policies. Each one is a fixed set of protocol scope tags plus a plain-language terms text you can edit before publishing. Need something else? Switch to Advanced.

3 · Your key

The policy is signed with a key that is created here, in your browser. The key is your identity; keep its backup to change the policy later under the same identity.

4 · Create and publish

You get three files to upload and one key backup to keep. The manifest is checked against the protocol's own acceptance rules before anything is offered for download.

    https://yourdomain.com/.well-known/proofmeta.json
    
        
    served as Content-Type: application/json, UTF-8, no byte-order mark. That's it — any agent can now discover and verify your terms.
    
        
    Recommended: allow cross-origin reads, so browser-based tools (like the Verifier) can fetch the file:
    
        
    
          CORS snippets — nginx · Apache · Vercel · Netlify / Cloudflare Pages

    # nginx
location = /.well-known/proofmeta.json {
    default_type application/json;
    add_header Access-Control-Allow-Origin "*";
}

# Apache (.htaccess)
<Files "proofmeta.json">
    Header set Access-Control-Allow-Origin "*"
</Files>

# Vercel (vercel.json → "headers")
{ "source": "/.well-known/proofmeta.json",
  "headers": [{ "key": "Access-Control-Allow-Origin", "value": "*" }] }

# Netlify / Cloudflare Pages (_headers)
/.well-known/proofmeta.json
  Access-Control-Allow-Origin: *
